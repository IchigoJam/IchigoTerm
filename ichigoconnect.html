IchigoConnect.jsの使い方

ESモジュールとして読み込み、ユーザー操作をきっかけにcreate()を呼び出します。

import { IchigoConnect } from "./IchigoConnect.js";

const ic = await IchigoConnect.create();

const button = await ic.send("?BTN()\n");
console.log(button);

const analog = await ic.send("?ANA()\n");
console.log(analog);

await ic.close();

メソッド

IchigoConnect.create()
シリアルポートの選択画面を表示し、115200bpsで接続します。
send(string)
受信済みバッファをクリアして文字列を送信し、50ms待ってから受信した先頭行を返します。
write(string)
文字列を送信します。応答は待ちません。コマンドを実行する場合は末尾に\nを付けます。
readLine()
次の1行を受信するまで待ち、改行を除いた文字列を返します。切断済みの場合はnullを返します。
readLines()
少なくとも1行を受信するまで待ち、その時点までに受信した行を文字列の配列で返します。
close()
読み書きを終了し、シリアルポートを切断します。
